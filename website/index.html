Intelligent Routing Strategies

fill-first

Default strategy. Use primary account first, fallback when exhausted. Fastest option.

round-robin

Distribute requests evenly across all accounts. Prevents quota exhaustion.

priority

Score-based selection. Prefer recently-used, healthy accounts with fewer errors.

cost-aware

Route to cheapest provider. Perfect for cost optimization at scale.

health

Avoid failing accounts. Select healthiest provider based on error history.

load-balance

Fair distribution. Pick least-used account every time.
